# Syrinx Visual Engine

A high-performance, modular Java graphics framework engineered for creative coding, real-time sketch generation, and 2D/3D canvas rendering.

## 🌟 Key Features

- **Real-Time Rendering:** Optimized 2D and 3D graphics rendering pipeline.
- **Interactive Canvas Engine:** Intuitive API for visual computing, generative art, and physics simulations.
- **Modular Java Core:** Scalable architecture built for custom extensions, shaders, and windowing backends.
- **Cross-Platform:** Runs seamlessly on Windows, macOS, and Linux environments.

## 📋 Architecture Overview

- **core:** High-speed rendering loops, shape vectorization, and matrix transformations.
- **pde:** Development environment and visual editor components.
- **java:** Language runtime execution and sketch compilation tools.

## 🛠️ Build Prerequisites

- **JDK:** Java Development Kit (JDK 17 or higher)
- **Build System:** Gradle 8.x
